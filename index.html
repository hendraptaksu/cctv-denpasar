Petunjuk peta

Ikon marker

CCTV ATCS Denpasar — klik untuk memutar stream.
CCTV Provinsi Bali — klik untuk memutar stream.
SPBU — klik untuk melihat daftar CCTV terdekat sesuai radius filter.
CCTV Kab. Badung — lokasi saja, belum ada stream publik.

Warna cluster

10Biru = grup CCTV (Denpasar/Bali). Angka = jumlah kamera, klik untuk zoom.
3Merah = grup SPBU.
5Abu-abu = grup titik Badung.

Cara pakai

  • Kamera se-titik dikelompokkan dalam satu marker; popup berisi daftar pilihan.
  • Klik marker merah lalu Tampilkan di grid untuk daftar CCTV terdekat SPBU itu.
  • Lingkaran oranye di peta = radius aktif dari SPBU terpilih.

Status putar

  • Semua kamera selalu bisa diklik; penanda hanya info dari hasil putar sebelumnya.
  • hijau = pernah terpancar; teks abu = percobaan sebelumnya gagal, silakan coba lagi.

Sumber data

atcs.denpasarkota.go.id, balisatudata.baliprov.go.id, Peta Smart City Badung, OpenStreetMap. Ikon = posisi perkiraan (koordinat asli jatuh di laut).
